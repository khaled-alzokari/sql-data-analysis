# SQL Data Analysis: Layoffs Dataset

Two MySQL projects built on a real-world layoffs dataset, following Alex The Analyst's SQL series. The first project cleans the raw data, and the second analyzes the cleaned result.

## Projects

| # | Project | Topics |
|---|---------|--------|
| 1 | [Data Cleaning](./01-data-cleaning) | Staging table, duplicate removal, standardization, NULL and blank values |
| 2 | [Exploratory Data Analysis](./02-exploratory-data-analysis) | Aggregations by company, industry, country, year and funding stage, rolling totals, top 5 companies per year |

## Tools
MySQL 8.0, MySQL Workbench

## Running the queries
1. Run 01-data-cleaning first. It creates the cleaned table layoffs_staging2.
2. Then run 02-exploratory-data-analysis, which queries that table.
